# Português de Concurso

Aplicativo web para estudar e treinar Língua Portuguesa para concursos: resumos por tema, questões comentadas (múltipla escolha e Certo/Errado), simulados e caderno de erros. Funciona no celular, pode ser instalado na tela inicial e abre offline depois do primeiro acesso.

Endereço: https://jorge-alvarez26.github.io/portugues-concurso/

As questões são originais, escritas no estilo das principais bancas. Não são questões reais.
